# 🐢 Сага о Чёрном Алмазе (Saga of Black Diamond)

> *«Прогрелись в котле — теперь мы готовы! Выбрали классы — надели оковы!»*

Добро пожаловать в официальный репозиторий легендарной нуар-саги о похождениях командира Агонита, чудаковатого кузнеца Борга, безумной мартышки Киссик, пирата Димачки, злого Миши с Сируса и нашей большой дружной семьи — участников гильдии и Discord-сообщества **«Чёрная Длань»**!

Этот репозиторий — цифровое рабочее место для совместного творчества, сценариев комиксов, вайб-кодинга персонажей и создания музыки в Suno AI.

## 🤝 Контрибьютим в сюжет: Как предложить свою идею (Pull Request)

Друзья, если вы придумали безумный поворот сюжета, грандиозное заклинание для Агонита или новую стычку с ограми-крупье, вы можете добавить свою идею прямо в наш канон! Для этого не нужно быть программистом — всё делается в браузере.

1. Зайдите на [github.com/bolshakovk/Comic_Project](https://github.com/bolshakovk/Comic_Project).
2. Создайте свою ветку (`idea-yourname`).
3. Добавьте свои правки, сцену или песню в `Storyline/Suggestions/`.
4. Нажмите **Create pull request** — мы прочитаем и вольём в основной канон!
