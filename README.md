# 🐢 Сага о Черном Алмазе (Saga of Black Diamond)

Добро пожаловать в репозиторий графической нуар-саги о похождениях Рыцаря Смерти Агонита, храбрых эльфиек, Серебряного рыцаря в желтых трусиках и загадочной черепашки, несущей Черный Алмаз!

Здесь мы храним весь канон, промты персонажей, объекты и черновики сюжетных линий для генерации комиксов на базе нейросетей. Этот репозиторий — наше цифровое рабочее место для совместного творчества.

## 📁 Структура проекта
* `/Characters/` — Промты и ключевые детали внешности героев (Агонит, Киссик, Серебряный рыцарь).
* `/Objects/` — Промты важных сюжетных вещей (Черный Алмаз, Черепашка).
* `/Storyline/` — Основная линия сюжета комикса (`comic_storyline.md`), а также папка предложений друзей (`/Suggestions/`).

## 🤝 Контрибьютим в сюжет: Как предложить свою идею (Pull Request)

Друзья, если вы придумали безумный поворот сюжета, грандиозное заклинание для Агонита или новую стычку с ограми-крупье, вы можете добавить свою идею прямо в наш канон! Для этого не нужно быть программистом — всё делается в браузере.

### Шаг 0: Регистрация на GitHub
Если у вас еще нет аккаунта:
1. Зайдите на [github.com](https://github.com/) и нажмите кнопку **Sign up** (Регистрация).
2. Введите свой email, придумайте пароль и классный никнейм.
3. Подтвердите email по ссылке из письма почты, и всё — вы великолепны!

### Шаг 1: Создайте свою ветку (Branch)
Чтобы мы не ломали основную историю (ветку `main`), вам нужно создать свою изолированную ветку для черновиков:
1. На странице этого репозитория найдите выпадающий список **`main`** (слева вверху, под количеством коммитов).
2. Кликните по нему и в текстовом поле введите название вашей новой ветки: например, `idea-Alex` или `casino-heist`.
3. Нажмите появившуюся строку **"Create branch: idea-Alex from main"**. Готово! Теперь вы работаете в личной копии проекта.

### Шаг 2: Напишите свою сцену
1. Убедитесь, что вы находитесь в вашей ветке (`idea-Alex`).
2. Отройте папку `Storyline/Suggestions/`.
3. Нажмите кнопку **Add file** -> **Create new file**.
4. В поле названия введите путь к вашей новой идее вместе с папкой для вашего ника (например: `Storyline/Suggestions/Ваш_Ник/turtle_heist.md`).
5. Вставьте туда структуру из нашего шаблона (подсмотрите в `Template_Friend/new_idea_template.md`). Расспишите детали сцены, диалоги героев и, если есть, промты на английском.
6. В самом низу страницы нажмите зеленую кнопку **Commit changes...**, напишите короткое описание "Добавил идею с ограблением" и сохраните.

### Шаг 3: Откройте Pull Request (Запрос на слияние)
Настало время показать нам вашу идею:
1. Перейдите на главную страницу репозитория (или на вкладку **Pull requests**).
2. Вы увидите большое желто-зеленое уведомление с названием вашей ветки и кнопку **Compare & pull request** — смело жмите на неё!
3. Напишите пару слов авторам о том, какую сцену вы привнесли.
4. Нажмите **Create pull request**.

Мы прочитаем, вынесем вердикт вашей гениальности, и вольем ваши наброски в основной сюжетный архив!
