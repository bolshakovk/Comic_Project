# Предложения по сюжету от друзей

Эта папка предназначена для хранения идей, черновиков и сценариев от ваших друзей.
Чтобы всё было структурировано и не путалось со основным каноном комикса:

1. **Создавайте папку с ником друга** (например `\Suggestions\Alex\`).
2. Внутри папки друга создавайте отдельные текстовые файлы или `.md` файлы для каждой сцены/идеи (например `idea_about_casino.md`).
3. При необходимости, можно использовать `new_idea_template.md` из папки `Template_Friend` как образец для оформления их идей.

Таким образом, мы всегда будем знать, кто предложил какую безумную идею для комикса (например, еще больше рыцарей в трусиках!), и сможем легко интегрировать лучшие варианты в основной `comic_storyline.md`.
